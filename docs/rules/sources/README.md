# Rule sources

## Canonical project source

- Local file: `../CANONICAL_RULES.md`
- Supplied by the project owner: 2026-07-23
- Key choices: exactly two opening Hideouts, no pass bonus draw, no Event or
  SHIFT cards.

This source takes precedence over every external rulebook or implementation.

- Current BGA help:
  https://en.doc.boardgamearena.com/Gamehelpfugitive

  https://geekdad.com/2016/06/fugitive/

  https://www.backerkit.com/c/projects/tim-fowers/fugitive-reprint-and-run
- Publisher-linked second-edition rules:
  https://drive.google.com/file/d/13Tjb3sMfy7NhPjbMvIVKJrykifYVhVpM/view
- User-provided second-edition Google document:
  https://docs.google.com/document/d/1GzGd9ekb38rxpj47YhAk0JHlNzXeI3LYYUq3ThgzPnU/edit?tab=t.0

The external sources are not normative for this project. In particular, the
second-edition bonus draw after passing is intentionally excluded. The 2017
PDF permits one or two opening Hideouts, while the canonical project rules and
the BGA help require exactly two. This project uses exactly two.
